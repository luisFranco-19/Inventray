# Plan to Provide App Description Prompt for Google Data Studio

## Objective
Create a detailed prompt describing the MBPos POS app's data structure and visualizations so the user can replicate and improve the analytics frontend in Google Data Studio.

## Steps
1. Analyze the app's data models from the code (sales, inventory, customers, expenses).
2. Identify key metrics and visualizations from analytics and reports screens.
3. Compile a comprehensive prompt including data sources, schema, and dashboard layout suggestions.
4. Provide the prompt to the user.

## Data Sources Identified
- Sales (venta): id, fecha, total, metodoPago, clienteNombre, totalItems, items (variants)
- Variants (variante): productoNombre, talla, color, precio, costo, stock
- Customers (cliente): nombre, telefono
- Expenses (gasto): fecha, monto, categoria
- Historical metrics for charts

## Visualizations to Include
- KPI metrics cards
- Time series line charts for sales trends
- Top products bar charts
- Payment methods pie/donut charts
- Inventory status tables
- Recent transactions lists
- Profitability breakdown
